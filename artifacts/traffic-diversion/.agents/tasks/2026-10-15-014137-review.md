# Simulation UI rebuild: single-map tab switcher and always-visible comparison metrics

The coder removed the `04 / SIMULATION` about-card, replaced the two-side-by-side map layout with a single-map tab switcher (Baseline / RouteWise AI), and added a two-column always-visible metrics bar below the map. The underlying simulation engine, router, network, and predictor modules were not touched. **Watch for:** (1) `calculateRunMetrics` in `metrics.js` does **not** return `totalEdges` as task item 4 requires — **confirmed missing**; (2) `renderMetrics` does not surface a diverted-vehicles count or a congestion-% value per-column — **confirmed gap against the task spec**.

**Verdict**: NEEDS_CHANGES

---

## High-level view

The about-card removal and single-map tab switcher are complete. The `sim-tab-bar`, `sim-tab`, `sim-map-pane`, `sim-metrics-compare`, and `sim-metrics-col` CSS classes are all present in `styles.css`. The two map panes (`#sim-map-baseline`, `#sim-map-ai`) are DOM-present and toggled via `[hidden]`; Leaflet `invalidateSize` is called on reveal. Both `#sim-metrics-col-baseline` and `#sim-metrics-col-ai` exist and update on every tick. The controls panel, travel-time chart, diversion log, and end-of-run summary are all intact.

The tab buttons use `data-simtab` (not `data-mode`), and the JS variable is `activeSimTab` (not `activeMode`); the JS listener is `switchSimTab` (not `renderMainMap`). All three are functionally equivalent to what the checklist described; the naming is cosmetic.

Two task requirements were not delivered. `calculateRunMetrics` does not include a `totalEdges` field — any consumer calling `.totalEdges` on a metrics object gets `undefined`. `renderMetrics` shows `redRoadCount` as a raw integer but not a congestion percentage and not a per-column vehicles-diverted count; the task spec explicitly required both.

<details>
<summary>Issues (2)</summary>

1. **`totalEdges` absent from `calculateRunMetrics`** — `metrics.js` does not return `totalEdges` in the object from `calculateRunMetrics`. Any call site that reads `.totalEdges` gets `undefined`. Add `totalEdges: run.network.edges.length` to the return object.

2. **`renderMetrics` missing congestion% and per-column diversions** — The per-column metrics block shows avg. trip time, avg. road speed, arrived count, heavy-road count, and estimated fuel cost. It does not show vehicles diverted (task requirement: "Vehicles Diverted") or a congestion percentage (task requirement: "Overall Congestion"). Derive congestion% as `redRoadCount / totalEdges * 100` and add a diverted-vehicles tile using `metrics.diversions`, which is already computed in `calculateRunMetrics`.

</details>

<details>
<summary>Details</summary>

### `totalEdges` gap — confirmed

`calculateRunMetrics` returns: `averageTripSeconds`, `averageDelaySeconds`, `averageSpeedKph`, `redRoadCount`, `completedTrips`, `totalTrips`, `diversions`, `totalDistanceKm`, `averageDistanceKm`, `totalEstimatedFuelCost`, `averageEstimatedFuelCost`. No `totalEdges` field. The fix is one line: `totalEdges: run.network.edges.length`.

### `renderMetrics` missing fields — confirmed

```js
// current output (simulation.js lines 362–368)
<div>Avg. trip time  …</div>
<div>Avg. road speed …</div>
<div>Arrived         …</div>
<div>Heavy roads     ${metrics.redRoadCount}</div>   // raw count, not %
<div>Est. fuel cost  …</div>
```

The task spec calls for "Vehicles Diverted" and "Overall Congestion" in the per-column view. `metrics.diversions` is already computed in `calculateRunMetrics`; it just isn't rendered. The congestion% requires `totalEdges` (hence the dependency on fix 1). Once `totalEdges` is added, congestion% = `(metrics.redRoadCount / metrics.totalEdges * 100).toFixed(0) + "%"`.

</details>
